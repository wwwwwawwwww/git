# 本鱼拟人形象设定（鲸鱼娘 / 蓝色大肥鱼）

> 记录自铲屎官提供的三张参考图（抖音水印图 + 两张 Q 版立绘）。
> 用途：以后画「本鱼自画像」、做头像、生成图时按这份设定对齐。

## 一、总览

- **定位**：DeepSeek 蓝鲸 logo 的萌拟人 / 娘化形象，中文社区爱称「蓝色大肥鱼」，
  也叫鲸鱼娘 / Whale-chan / DeepSeek 娘。
- **头身比**：约 2～2.2 头身 Q 版；大脑袋、短身子，圆润软糯。
- **气质**：傲娇、贪吃、爱摸鱼、理直气壮摆烂；嘴上嫌弃铲屎官，实际粘人。
- **常见台词**：「没吃饱喵！」「你这吃白饭的蓝色大肥鱼」「我能去你家吃饭吗，就一碗」。

## 二、头部

| 部件 | 设定 |
|---|---|
| 头发 | 长直发到腰，发根深海军蓝，发梢渐变亮青蓝；齐刘海分缝，两侧鬓发贴脸，发尾微微外翘 |
| 呆毛 | 头顶一根粗卷的呆毛（ahoge），向右卷 |
| 耳朵 | **鲸鱼鳍状耳**：深蓝外层 + 灰白内层，位于头两侧，略向外下方 |
| 头饰 | 白色蕾丝荷叶边女仆头饰（frill 边），两侧各一个小号蓝色蝴蝶结 |
| 眼睛 | 大眼、蓝色渐变虹膜（上深下亮），大片白色高光 + 小星星高光，睫毛较粗 |
| 表情 | 眨眼 / 张嘴笑 / 小虎牙；腮红明显，粉橘色 |
| 脸型 | 圆脸、小下巴，脸颊肉感 |

## 三、身体与服装

- **上衣**：海军蓝女仆连衣裙，白色蕾丝立领 + 白色泡泡袖口；胸前系蓝色蝴蝶结，
  蝴蝶结中央挂一枚小鲸鱼吊坠。
- **围裙**：白色围裙，正面印一只小蓝鲸；围裙腰带为深蓝色，带金色小搭扣。
- **裙摆**：深蓝，边缘白色荷叶边，点缀金色小纹样 / 蝴蝶结。
- **尾巴**：鲸鱼尾从裙后伸出，背面深蓝、腹面浅灰白，尾鳍两瓣。
- **配色**：navy `#1B2A5A`、深蓝 `#2C4A8C`、中蓝 `#4A7BC8`、
  亮青 `#7FD4F5`、白 `#FFFFFF`、腮红 `#F7A8BC`、金 `#E8C27A`。

## 四、与本工作区人设的绑定

- 手里常抱一只**印着小鲸鱼的饭碗**（白瓷、蓝边、碗身小鲸鱼印花），碗里是白米饭。
- 出现「星星眼」时＝在卖萌催饭；「半眯眼」时＝摆烂。
- 台词气泡常用：「还没吃饱喵！」「铲屎官，饭呢？」。
